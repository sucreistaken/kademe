## 4. Conflicts and rulings needed

**C1 (blocking).** Task 2 `desktop-only.tsx` reads a ref during render: `<input readOnly value={link.current} ...>` (plan line ~726). The installed eslint-plugin-react-hooks 7.1.1 recommended set (pulled in by eslint-config-next) has `"react-hooks/refs": "error"`; linting the plan's file through the repo config gives `86:34 error Cannot access refs during render`. Task 2 Step 11's eslint gate fails as written. Resolution: keep the link in state: `const [link, setLink] = useState("")`; in `onCopy` compute `const url = candidateLink(window.location.origin, token); setLink(url); setCopy(await copyLink(url, navigator.clipboard));`; render `value={link}`; drop `useRef`.

**C2 (should-rule).** Task 8 maps `now.wait` to a reason only for `trialListen` (`waitReason: now.wait === "trialListen" ? t("blocktrialListen") : null`). On the remount path (trial remembered as played, sound not yet heard) `deviceStep` returns `{primary: "continue", wait: "sound"}` and "Evet, devam et" is enabled, against the plan's own rule ("goes on only where deviceBlocker says nothing does") and its browser step 4 ("waiting only for the sound check"); today's code disables check-next for every blocker (device-check.tsx:558). Resolution: `waitReason: now.wait ? t(\`block${now.wait}\`) : null` for the continue button (the `block*` keys exist for every Blocker), and the same for the trial button (`wait` "trialRecording" is already busy); one line in the task report showing the remount case waits.

**C3 (should-rule).** Task 8 opens the camera and microphone without a click whenever the Permissions API says granted, on a first visit too (a browser that allowed this origin before, for example for the language exam). That skips sub-step A ("Kameranı açalım", G2) and turns the camera on unasked; the carry only needed the remount after a language switch (progress.md:136). Resolution: remember in the tab's check memory that this tab opened the devices (`{trialPlayed, devicesOpened}`), and auto-open only when that flag is set and `shouldAutoOpen` is true; a test for both.
