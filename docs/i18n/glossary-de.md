# German glossary for the Kademe panel

Register: formal "Sie". Wording follows `auth.de.json` and `candidate.de.json`. Gender-neutral
phrasing where it stays short ("Lernende", "lernende Person", "Bewertende"). The product name
"Kademe", CEFR levels (A1..C2) and file column names in the CSV upload (`type`, `section`, ...)
stay unchanged. No em dash anywhere.
